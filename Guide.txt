Installation Guide du coremis en local
0. cd anies_core_mis_be
1. pip install -r requirements.txt
2. python3 modules-requirements.py ../openimis.json > modules-requirements.txt
2.1: Assurez-vous que le liens d'installation dans le fichiers modules-requirements.txt est préfixé par -e pour installer en local. Par exemple:
-e git+https://github.com/sackofils/openimis-be-core_py.git@release/25.04#egg=openimis-be-core
-e git+https://github.com/openimis/openimis-be-individual_py.git@release/25.04#egg=openimis-be-individual
...
3. python3 -m pip install -r modules-requirements.txt
4. execute the following script in to your database:
    - process_import_beneficiaries.sql
    - process_import_beneficiaries_group.sql
